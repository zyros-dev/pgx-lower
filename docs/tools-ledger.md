# Tools Ledger

This ledger records the inherited `tools/` tree after the repo hygiene follow-up.
It prevents future cleanup from becoming guesswork.

## Keep

| Path | Reason |
| --- | --- |
| `tools/CMakeLists.txt` | Builds checked-in tool targets used by CMake. |
| `tools/build-tools/` | Contains `runtime-header-tool.cpp`, built from `CMakeLists.txt`; generated CMake files are not kept. |
| `tools/clion/` | CLion/Gateway compiler wrappers used by generated `compile_commands.json`. |
| `tools/mlir-tools/` | CMake-built MLIR command-line tools. |
| `tools/python/` | CMake pybind integration. |
| `tools/sourcemap/` | CMake-built sourcemap tool used by profiling scripts. |
| `tools/sql/` | CMake-built SQL tool. |
| `tools/sqlite-tester/` | CMake-built sqlite tester. |
| `tools/validate_tpch.py` | Used by `Makefile` regression validation. |
| `tools/generate_tpch_data.py` | Used by `Makefile tpch-data`; duplicate with `benchmark/generate_tpch_data.py` should be resolved in a later benchmark cleanup. |

## Defer

| Path | Reason |
| --- | --- |
| `tools/bench.py` | Legacy benchmark driver; current `just bench` uses `benchmark/tpch/run.py`, but Makefile still exposes `pgx-bench`/`psql-bench`/`lingo-bench`. |
| `tools/debug-query.sh` | Debug helper; no recipe owner identified in this pass. |
| `tools/debugging/` | Debug helper scripts; keep until profiling/debug workflow is reviewed. |
| `tools/docker/` | Legacy Dockerfile for inherited LingoDB-style toolchain; not part of current dev container path. |
| `tools/generate/` | TPC-H/SSB generation helpers; unclear whether benchmark workflows still need them. |
| `tools/interactive-tpch-debug.sh` | Manual debug helper; no recipe owner identified in this pass. |
| `tools/lingodb-debug/` | Manual LingoDB comparison/debug helper; not in normal test path. |
| `tools/profile-tools/` | Profiling UI/data scripts referenced by profiling helper scripts, but not by normal `just` recipes. |
| `tools/relalg_playground.sh` | Manual playground helper. |
| `tools/repeat_test.sh` | Manual test loop helper. |
| `tools/run-relalg.sh` | Used by `Makefile run-relalg`; keep or move after deciding whether that target stays. |
| `tools/scripts/` | Mixed profiling/reproduction scripts; needs per-file review before deletion. |
| `tools/tpch-debug.sh` | Manual debug helper; no recipe owner identified in this pass. |
